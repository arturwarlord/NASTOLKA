# 3D forest model credits

The forest renderer optionally loads the **Oak street tree, light canopy** GLB from Innerscene's public-domain CC0 library:

- Model page: https://www.innerscene.com/tools/library/3d-parts/oak-street-tree-light-canopy-a469b6df
- Direct model endpoint: https://www.innerscene.com/api/library/oak-street-tree-light-canopy-a469b6df/download
- License: CC0 / public domain; permitted for commercial use and modification.

The model is loaded at runtime through Three.js GLTFLoader. If the model host, network, or module CDN is unavailable, the renderer keeps its procedural trees instead. The model is not vendored into this repository, so runtime availability depends on the external host.
